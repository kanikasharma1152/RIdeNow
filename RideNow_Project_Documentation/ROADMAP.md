# 5-Week Roadmap

Week 1: architecture, Git, React, FastAPI, PostgreSQL, authentication.

Week 2: users, drivers, vehicles, ride APIs, ride state machine, fare.

Week 3: maps, location, WebSockets, Redis, live tracking, notifications.

Week 4: payments, ratings, admin dashboard, analytics, testing.

Week 5: AI/ML, ETA, demand, driver recommendation, Docker, deployment and final documentation.
