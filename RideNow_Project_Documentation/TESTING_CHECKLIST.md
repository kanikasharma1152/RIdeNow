# Testing Checklist

Authentication: valid login, wrong password, duplicate email, protected routes, logout, role permissions.

Ride: booking, no nearby driver, accept/reject, cancellation, start/end, fare.

Realtime: WebSocket connection, location updates, reconnect and correct event delivery.

Payments: success, failure, duplicate-payment prevention and receipt.

AI: valid prediction input, missing input handling, demand prediction, driver recommendation and anomaly detection.

Quality: unit tests, integration tests, API tests, frontend tests, logging and error handling.
