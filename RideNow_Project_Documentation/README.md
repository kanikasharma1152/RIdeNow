# RideNow — Uber-Inspired Ride Booking Platform

A full-stack learning and portfolio project that demonstrates how a real-world ride-booking system is designed, developed, tested and deployed.

## Roles
- Rider: book, track, pay and rate rides
- Driver: go online, receive requests, accept rides and manage earnings
- Admin: manage users, drivers, rides, payments and analytics

## Core Features
Authentication, role-based access, rider/driver profiles, vehicles, ride booking, driver matching, fare calculation, maps, live location, WebSockets, Redis, payments, notifications, ratings, ride history and admin analytics.

## AI Features
- ETA prediction
- Demand prediction
- Dynamic fare prediction
- Intelligent driver recommendation
- Fraud/anomaly detection

## Tech Stack
Frontend: React + Vite
Backend: FastAPI + Python
Database: PostgreSQL + SQLAlchemy
Cache: Redis
Realtime: WebSockets
Maps: Google Maps API or Mapbox
Payments: Razorpay/Stripe
Notifications: Firebase
AI/ML: NumPy, Pandas, Scikit-learn
Deployment: Docker + Docker Compose
Version Control: Git + GitHub

## Main Learning Flow
Requirement → Architecture → Database → API → Backend → Frontend → Testing → Deployment → AI
