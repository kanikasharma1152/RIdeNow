# Features That Can Impress

High priority:
- Live driver tracking
- Intelligent driver matching
- Real-time ride status
- AI ETA prediction
- AI demand forecast
- Admin analytics

Optional:
- Scheduled rides
- Promo codes
- SOS/safety tools
- In-app chat
- Multi-language support
- Driver heatmap
- Cancellation analysis
- Loyalty/rewards

Rule: build a solid MVP first. Add advanced features only after the core flow is stable.
